# 나만의 프롬프트 관리 (Prompt Manager)

파편화되어 흩어진 프롬프트를 한곳에서 체계적으로 관리하는 **파이썬 콘솔 프로그램**입니다.
카테고리별 분류, 키워드 검색, 즐겨찾기, 상세 보기는 물론 JSON 저장/불러오기와
Markdown 내보내기까지 지원합니다.

프롬프트 데이터는 파이썬의 **리스트(list)** 와 **딕셔너리(dict)** 로 관리되며,
각 프롬프트는 `제목`, `내용`, `카테고리`, `즐겨찾기 여부`를 포함합니다.

## 실행 방법

Python 3.10 이상이 필요합니다.

```bash
python3 prompt_manager.py
```

> 이 환경에서는 3.12를 사용했습니다: `python3.12 prompt_manager.py`

실행하면 메뉴가 출력되고, 번호를 입력해 기능을 선택합니다.
잘못된 번호를 입력하면 안내 메시지를 보여준 뒤 다시 메뉴로 돌아갑니다.
`0`을 입력하면 프로그램이 종료됩니다.

프로그램 실행 중 추가·수정·즐겨찾기한 내용은 유지되지만, **종료 시 초기화**됩니다.
(원한다면 메뉴 `11`로 JSON 저장 후 다음 실행에서 `12`로 불러올 수 있습니다.)

## 기능 목록

### 필수 기능
| 번호 | 기능 | 설명 |
|------|------|------|
| 1 | 프롬프트 추가 | 제목·내용·카테고리를 입력해 새 프롬프트 등록 (빈 값은 재입력) |
| 2 | 프롬프트 목록 | 전체 프롬프트를 번호·카테고리·즐겨찾기(⭐)와 함께 출력 |
| 3 | 카테고리별 조회 | 선택한 카테고리의 프롬프트만 출력 |
| 4 | 프롬프트 검색 | 제목 또는 내용에 키워드가 포함된 프롬프트 검색 |
| 5 | 프롬프트 상세 보기 | 번호로 선택한 프롬프트의 전체 내용 표시 |
| 6 | 즐겨찾기 관리 | 번호로 즐겨찾기 추가/해제 |
| 7 | 즐겨찾기 목록 | 즐겨찾기된 프롬프트만 모아 보기 |
| 0 | 종료 | 프로그램 종료 |

### 보너스 기능
| 번호 | 기능 | 설명 |
|------|------|------|
| 8 | 프롬프트 수정 | 제목·내용·카테고리 수정 (CRUD) |
| 9 | 프롬프트 삭제 | 번호로 프롬프트 삭제 (CRUD) |
| 10 | 조회수 Top 목록 | 상세 보기 시 기록된 조회수 기준 내림차순 정렬 |
| 11 | JSON으로 저장 | 전체 프롬프트를 `prompts_data.json`으로 저장 |
| 12 | JSON에서 불러오기 | 저장된 JSON 파일에서 프롬프트 불러오기 |
| 13 | Markdown 내보내기 | 카테고리별 `.md` 파일을 `exports/` 폴더로 내보내기 |

## 카테고리

프롬프트는 다음 6개 카테고리로 분류합니다.

- **텍스트 생성** — 글쓰기·요약·번역 등 텍스트 결과물을 위한 지시문
- **이미지 생성** — 이미지 생성 모델용 키워드/스타일 프롬프트
- **영상 생성** — 영상 스크립트·장면 구성 프롬프트
- **페르소나** — 특정 역할·성격을 부여하는 페르소나 설계 프롬프트
- **자동화** — 반복 작업 자동화(요약·분류 등)를 위한 프롬프트
- **기타** — 위 분류에 속하지 않는 프롬프트

카테고리는 미리 정의된 목록에서 선택하거나 직접 입력할 수 있습니다.

## 프로젝트 구조

```

```

기본 데이터로 이전 미션에서 작성한 프롬프트 5개가 미리 등록되어 있습니다.

## 코드 구조 (함수 분리)

모든 코드를 한 함수에 몰아넣지 않고 기능별로 함수를 분리했습니다.

- `show_menu()` — 메뉴 출력
- `add_prompt()` — 프롬프트 추가
- `show_list()` — 목록 출력
- `show_by_category()` — 카테고리별 조회
- `search_prompt()` — 검색
- `show_detail()` — 상세 보기 (조회수 기록)
- `toggle_favorite()` / `show_favorites()` — 즐겨찾기 관리/목록
- `edit_prompt()` / `delete_prompt()` — 수정/삭제
- `show_top_viewed()` — 조회수 Top 목록
- `save_to_json()` / `load_from_json()` — JSON 저장/불러오기
- `export_markdown()` — Markdown 내보내기
- `main()` — 메뉴 반복 및 입력 분기
