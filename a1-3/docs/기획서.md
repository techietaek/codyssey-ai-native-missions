# 서비스 기획서 — 취미핏 (HobbyFit)

## 1. 서비스 개요

- **서비스명:** 취미핏 (HobbyFit)
- **한 줄 소개:** 성향과 여건을 입력하면 AI가 맞춤 취미 3가지를 추천해주는 서비스
- **목적:** 새 취미를 찾고 싶지만 선택지가 많아 시작을 망설이는 사람들의 "결정 피로"를 줄이고, 오늘 바로 실행할 수 있는 구체적 첫걸음까지 제시한다.
- **타겟 사용자:**
  - 새로운 취미를 찾는 직장인·대학생
  - 번아웃·무기력을 겪어 환기가 필요한 사람
  - 예산·시간 제약 안에서 현실적인 취미를 찾는 사람

## 2. 페이지 / 섹션 구성

한 페이지(SPA 형태) 안에서 앵커(`#`) 기반 네비게이션으로 이동한다. 모바일에서는 햄버거 메뉴로 전환.

| 순서 | 섹션 | 내용 |
|:---:|------|------|
| 1 | **홈 (Hero)** | 서비스 캐치프레이즈, CTA 버튼, 핵심 지표 |
| 2 | **서비스 소개** | "입력 → 분석 → 시작" 3단계 동작 방식 카드 |
| 3 | **AI 추천** | 핵심 기능. 입력 폼 + AI 결과 카드 |
| 4 | **FAQ** | 자주 묻는 질문 (아코디언) |
| 5 | **문의하기** | 이름·이메일·내용 폼 (클라이언트 검증) |

- **네비게이션 방식:** 상단 고정(sticky) 헤더의 메뉴 클릭 → 해당 섹션으로 부드럽게 스크롤. 모바일은 토글 메뉴.

## 3. AI 기능 설계

- **사용할 AI:** Google Gemini API (`gemini-3.6-flash` — 빠르고 저렴)
- **제공 가치:** 검색·비교 없이 30초 만에 나에게 맞는 취미와 시작 팁을 얻는다.

### 입력 (사용자 → 시스템)

| 항목 | 형태 | 필수 |
|------|------|:---:|
| 성향 | 내향적 / 외향적 / 중간 | ✅ |
| 주당 여가시간 | 1~2h / 3~5h / 6h+ | ✅ |
| 월 예산 | 3만원 이하 / 3~10만원 / 10만원+ | ✅ |
| 선호 장소 | 실내 / 실외 / 상관없음 | ✅ |
| 자유 설명 | 텍스트 (최대 300자) | 선택 |

### 출력 (시스템 → 사용자)

취미 **3가지**, 각각:
- `title` — 취미 이름
- `reason` — 이 사람에게 잘 맞는 이유 (1~2문장)
- `tip` — 오늘 바로 시작하는 구체적 첫걸음 (1문장)

→ 화면에는 3개의 카드로 렌더링.

### 실패 처리 기준

| 상황 | 판정 위치 | 사용자 안내 |
|------|-----------|-------------|
| **빈 입력**(필수값 누락) | 프론트 + 백엔드(400) | "성향·여가시간·예산·선호 장소는 필수 항목입니다." |
| **API 오류**(4xx/5xx) | 백엔드 → 프론트 | "추천을 불러오지 못했어요. 잠시 후 다시 시도해 주세요." |
| **지연/타임아웃**(25초 초과) | 프론트(AbortController) | "응답이 지연되고 있어요. 잠시 후 다시 시도해 주세요." |
| AI 응답 해석 실패 | 백엔드(502) | "AI 응답을 해석하지 못했습니다. 다시 시도해 주세요." |

## 4. AI 기능 테스트 시나리오

| 케이스 | 입력 | 기대 결과 |
|--------|------|-----------|
| 정상 | 내향적 / 주 3~5시간 / 3~10만원 / 실내 | 취미 3개 카드 표시 |
| 빈 입력 | 성향 미선택 | "필수 항목입니다" 안내 표시 |
| 긴 입력 | 자유 설명 300자 | 정상 응답 또는 지연 시 안내 문구 |
| 서버 키 미설정 | (환경변수 없음) | "API 키가 설정되지 않았습니다" 안내 |

## 5. 기술 스택 / 아키텍처

- **프론트:** 순수 HTML/CSS/JS (프레임워크 미사용)
- **백엔드:** Vercel Serverless Functions (Python, `api/recommend.py`)
- **AI:** Gemini API — 서버(백엔드)에서만 호출하여 키를 노출하지 않음
- **배포:** GitHub → Vercel 자동 배포
- **보안:** API 키는 환경 변수(`GEMINI_API_KEY`)로만 관리

```
[브라우저] --fetch('/api/recommend')--> [Vercel Python 함수] --> [Gemini API]
     ^                                                              |
     └───────────────── JSON 추천 결과 ─────────────────────────────┘
```
